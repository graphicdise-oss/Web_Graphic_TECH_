## 🔴 สำคัญมาก (ต้องแก้ก่อน Launch)

### ✅ 1. รูปภาพส่วนใหญ่ยังเป็น Placeholder

- **ปัญหา:** Portfolio ทั้ง 8 ชิ้น (จาก 9) และ Hero Cards 2 ใน 3 ชิ้น ใช้ `banner.png` ไฟล์เดียวซ้ำกัน

### ✅ 2. SEO Meta Tags ไม่สมบูรณ์

- **ปัญหา:** `index.html` มีแค่ `<meta name="description" content="Graphic TECH">` — สั้นเกินไปและไม่มี keywords
- **ปัญหา:** ไม่มี Open Graph Tags (`og:title`, `og:image`, `og:description`) สำหรับการแชร์บน Social Media
- **วิธีแก้:** เพิ่ม Meta Tags ทั้ง SEO และ OG ในทุกหน้า
- **สถานะการแก้ไข:** 🟢 **แก้ไขแล้ว** (เพิ่ม Description แบบสมบูรณ์, ใส่ Keywords และ Open Graph Tags ลงใน `index.html` แล้ว)

### ✅ 3. testimonials.js ถูกเรียกใช้แต่ไม่มีไฟล์

- **ปัญหา:** หน้า `service-uiux.html` บรรทัด 219 เรียก `../js/testimonials.js` แต่ไฟล์นี้ไม่มีในโปรเจกต์ → จะเกิด 404 Error ใน Console
- **วิธีแก้:** สร้างไฟล์ `js/testimonials.js` หรือลบบรรทัดนั้นออก
- **สถานะการแก้ไข:** 🟢 **แก้ไขแล้ว** (สร้างไฟล์ `js/testimonials.js` เปล่าเตรียมไว้เพื่อไม่ให้เกิด 404 Error)

### ✅ 4. ไม่มี favicon ที่ถูกต้อง

- **ปัญหา:** `index.html` บรรทัด 9 อ้างอิง `assets/images/logo.png` สำหรับ favicon แต่ไม่ได้มี `.ico` format — browser บางตัวแสดงผลได้ไม่ดี
- **วิธีแก้:** เพิ่ม favicon.ico หรือ favicon.png ขนาดมาตรฐาน (32x32, 180x180)
- **สถานะการแก้ไข:** 🟢 **แก้ไขแล้ว** (เพิ่ม `sizes="32x32"` และ `<link rel="apple-touch-icon" sizes="180x180">` ลงใน `index.html` และทุกหน้าย่อยแล้ว)

### ✅ 5. Hero Background Video 404 Error

- **ปัญหา:** `index.html` เรียกใช้ `bg-hero.jpg` และ `hero-loop.mp4` แต่ไม่มีไฟล์ ทำให้เกิดข้อผิดพลาด 404 ใน Browser Console
- **วิธีแก้:** ลบแท็ก `<div class="hero-media">` ออก โดยยังคงพื้นหลัง SVG Grid และ Animated Orbs ที่สวยงามไว้
- **สถานะการแก้ไข:** 🟢 **แก้ไขแล้ว** (ไม่พบข้อผิดพลาด 404 บนหน้าแรกแล้ว)
